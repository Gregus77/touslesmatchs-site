# Vote IA + Internationalisation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the public "Chief decides" story with a product model based on 5 independent AI votes, convergence, unanimity, and multilingual lead/customer handling.

**Architecture:** Keep the current monolithic API and static pages. Add vote metadata to Concile responses, expose only public-safe vote labels, and prepare Brevo/Telegram fields to route by language and convergence tier.

**Tech Stack:** Node.js/Express in `scripts/api_server.js`, static HTML/JS in `public/`, Brevo contacts, Telegram bot messages, existing SQLite tables.

## Global Constraints

- French remains the default language.
- Public copy must avoid "pari conseille"; use "signal conseille", "selection IA", "signal valide", or "convergence statistique".
- Do not expose agent/provider names, quota failures, API keys, prompts, or internal model errors to clients.
- Preserve current paid access, Stripe, Telegram, Brevo, Live IA, and bookmaker links.
- Always back up before production deployment.
