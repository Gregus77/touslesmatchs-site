# Origine des visites sociales TousLesMatchs

Le compteur du dashboard administrateur lit la table existante page_views.

- Visiteurs estimés : nombre de pseudonymes IP distincts par période. Ce n'est pas un décompte exact des personnes : IP partagées, VPN, bloqueurs, etc.
- Pages vues attribuées : chargements avec paramètres UTM ou domaine référent reconnu. Ce ne sont pas des sessions uniques.
- Aujourd'hui / 7 jours / 30 jours, heure de Paris. Facebook, Instagram, YouTube, TikTok.
- Les clics /go/tiktok redirigés vers Telegram ne comptent pas comme une arrivée sur le site.
- Les visites d'avant déploiement sont exploitables seulement si un UTM ou référent avait été capturé. Aucune provenance inventée.
- Aucune nouvelle collecte d'IP, identifiant, cookie ou empreinte navigateur. Le suivi antérieur reste soumis aux obligations légales applicables et au consentement lorsque requis.
