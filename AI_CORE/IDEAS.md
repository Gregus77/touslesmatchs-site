# IDEAS — Idees a explorer

## Monetisation
- Pack "Signal Fort" : notification instantanee quand confiance >= 85% (tier premium)
- Analyse post-match automatique (pourquoi gagne/perdu) pour fideliser
- API B2B pour affilies / sites tiers
- Programme parrainage (1 mois offert pour 3 filleuls)

## Produit
- PWA avec notifications push Signal Fort
- Mode sombre sur le site
- Historique graphique des performances (courbe winrate)
- Comparateur de cotes integre (sans redirection bookmaker)
- Badge "Serie en cours" quand 5+ wins consecutifs

## IA / Algorithme
- Ponderer les agents par leur winrate individuel (agent weighting)
- Ajouter un agent specialise tennis (surface + classement ATP)
- Meta-learning : ajuster les seuils de confiance selon le winrate reel
- "But en 1ere mi-temps" : tracker specifiquement les conditions gagnantes
- Backtesting automatique sur les 6 derniers mois

## Marketing
- TikTok : format "IA vs Bookmaker" (challenge viral)
- Thread Twitter automatique post-win
- Newsletter Brevo "recap semaine" avec best picks
- Partenariat micro-influenceurs sport (5-10k followers)

## Technique
- CDN (Cloudflare) pour accelerer le site
- Cache Redis pour les matchs en direct
- Webhook Telegram pour interactions (au lieu de polling)
- Monitoring Uptime (alertes si site down)
- Tests automatises sur les filtres de cotes
